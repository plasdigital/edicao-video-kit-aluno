# Glossário da transcrição

O Whisper não conhece nome de ferramenta e escreve como ouviu. A skill `transcrever-video` já traz uma lista pronta (HyperFrames, Remotion, FFmpeg, Claude Code, ChatGPT e outras). Aqui entram **os termos do seu assunto**.

- **troca** — o erro só existe como erro: aplica sozinho (depois que você vê a lista).
- **aviso** — o "erro" também é palavra de verdade: o agente só mostra o trecho e você decide.

Escreva o texto exatamente como apareceu na transcrição, sem regex.

| Tipo | O Whisper escreveu | O certo |
|---|---|---|
| troca | Hype Frames | HyperFrames |
| aviso | remoção | Remotion (ou a palavra 'remoção') |

Acrescente uma linha por termo. A primeira linha da tabela (cabeçalho) é ignorada.
