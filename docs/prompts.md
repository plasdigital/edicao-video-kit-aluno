# Prompts da aula

O desenho de som integra a edição: siga [transições e efeitos sonoros](transicoes-e-som.md). Use o prompt desse guia para aprofundar ou ajustar whooshes, ticks e mixagem; o agente deve preservar a voz e posicionar efeitos pelos tempos finais.

## Editar a introdução

> Leia as instruções desta pasta e use as skills oficiais do HyperFrames para editar a gravação em entrada/. Quero uma introdução dinâmica para YouTube com motion design em HTML, CSS, SVG e JavaScript. Use minhas referências em referencias/. Minha paleta é [CORES]; você tem liberdade de fontes. Analise a fala e planeje as animações pelo significado. Alterne câmera cheia, janela lateral com borda animada e cenas gráficas completas. Ao falar de um prompt, mostre um comando sendo digitado e se transformando em composição. Ao falar de animação, demonstre a animação. Use textos grandes, máscaras, camadas, ícones e gráficos legíveis; a linha dos gráficos deve avançar com os números. Use apenas dados fornecidos ou indique claramente que são ilustrativos. Pode cobrir minha imagem ou usar tela inteira. Recorte minha silhueta apenas se o resultado ficar limpo; caso contrário, use janela lateral. Sincronize efeitos sonoros discretos à animação sem prejudicar a voz. Confira sincronização labial antes de corrigir áudio. Preserve os originais. Gere uma prévia, revise, exporte MP4 de alta qualidade e entregue o projeto editável com relatório. Use recursos locais; se faltar material indispensável, peça. Não use geração paga nem publique.
